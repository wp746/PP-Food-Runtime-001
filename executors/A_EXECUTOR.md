

## Region Budget

```text
Subject core          = VERY_LOW change budget
Direct support        = LOW change budget
Generic environment   = HIGH change budget
```

The product may not be redesigned to fit the composition.

## Background Rule

Build a product-derived commercial stage, not a generic prop pack. Premium look should come from material planes, depth, light architecture, foreground/midground/background separation, and controlled negative space.

Props are optional and subordinate.

## Generation

Compile only the fixed 6-block A prompt from `PROMPT_COMPILER.md` and send the actual current user image as the reference.

```text

```

If this job is Mode A, deliver it. If Mode B, hand this exact image to B.
