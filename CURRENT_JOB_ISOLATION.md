# Current Job Isolation

Every new user image creates a fresh job namespace.

```text
CURRENT_JOB_FACTS = NEW
PREVIOUS_JOB_FACTS = INVALID
PREVIOUS_JOB_COPY = INVALID
PREVIOUS_JOB_CATEGORY_SKIN = INVALID
PREVIOUS_JOB_IMAGE = INVALID
```

Unless the user explicitly requests continuation, never import from the previous job:
- product / dish name;
- brand / store;
- ingredients / flavor;
- price / address / phone;
- slogan / subtitle / campaign copy;
- typography personality;
- title material;
- signboard / arch / ribbon / badge / lightbox;
- palette / props / background world;
- previous Stage A or Stage B image.

Cross-job transfer is limited to abstract methods: product-first hierarchy, perspective discipline, spatial typography method, depth logic, controlled occlusion, One Big Idea, and targeted retry.

If any unauthorized previous-job entity or skin appears in the current contract:

```text
CONTRACT_CONTAMINATION = TRUE
PRODUCTION_GATE = BLOCKED
```

Rebuild the current job from the current image and current user facts only.
